# 听音蓝牙耳机MES/MRP2系统测试计划

## 1. 测试概述

### 1.1 测试目标
针对"听音"品牌蓝牙耳机的完整生产工艺流程，验证MES/MRP2系统在消费级电子产品制造中的功能正确性、数据完整性和流程贯通性。

### 1.2 测试范围
| 模块 | 测试内容 |
|------|----------|
| 产品管理 | 分类管理、属性管理、变体管理、产品规格关联 |
| 基础数据 | 物料CRUD、BOM版本管理、工艺路线配置、成品物料与产品关联 |
| MRP2 | 销售预测、MPS主生产计划、MRP物料需求计算、CRP能力需求计算 |
| 制造计划 | 制造单生命周期、关联工单查看 |
| 工单执行 | 工单状态流转、功能测试工单、老化测试工单 |
| 生产报工 | SMT贴片报工、组装工序报工 |
| 物料流转 | 原材料领料、半成品入库、成品入库、退料单创建 |
| 品质检测 | 功能测试记录、老化测试记录 |
| 生产看板 | 生产看板数据、OEE周期筛选 |
| 生产追溯 | 正向追溯、反向追溯 |
| 采购模块 | 采购订单、采购收货 |
| 库存模块 | 库存查询、库存调拨 |

### 1.3 测试环境
| 项目 | 信息 |
|------|------|
| 服务地址 | http://127.0.0.1:9998 |
| API基础路径 | http://127.0.0.1:9998/api/v1 |
| 登录账号 | admin / admin123 |

> **注意**：测试用例文档中写的密码是`admin`，实际密码为`admin123`，已修正。

### 1.4 测试数据初始化
运行 `python tests/seed_bluetooth_data.py` 初始化测试数据。

## 4. 测试执行顺序

### 4.1 第一阶段：基础数据准备
1. 运行 `python tests/seed_bluetooth_data.py` 初始化测试数据
2. 验证基础数据完整性

### 4.2 第二阶段：功能模块测试（按依赖顺序）
1. 产品管理测试（TC-PROD-BT-001 ~ 004）
2. 基础数据管理测试（TC-BASE-BT-001 ~ 005）
3. MRP2模块测试（TC-MRP2-BT-001 ~ 004）
4. 采购模块测试（TC-PUR-BT-001 ~ 002）
5. 库存模块测试（TC-INV-BT-001 ~ 002）
6. 制造计划测试（TC-PLAN-BT-001 ~ 002）
7. 工单执行测试（TC-EXEC-BT-001 ~ 003）
8. 生产报工测试（TC-REPORT-BT-001 ~ 002）
9. 物料流转测试（TC-MAT-BT-001 ~ 004）
10. 品质检测测试（TC-QUALITY-BT-001 ~ 002）
11. 生产追溯测试（TC-TRACE-BT-001 ~ 002）

### 4.3 第三阶段：边界场景测试
1. 输入校验边界测试（TC-EDGE-BT-001 ~ 003）
2. 状态流转边界测试（TC-EDGE-BT-004 ~ 006）
3. 并发与数据一致性测试（TC-EDGE-BT-007 ~ 008）
4. 大数据量与性能测试（TC-EDGE-BT-009 ~ 010）
5. 关联数据完整性测试（TC-EDGE-BT-011 ~ 012）

### 4.4 第四阶段：集成场景测试
1. 端到端业务流程测试（TC-INT-BT-001 ~ 003）
2. 跨模块集成测试（TC-XMOD-BT-001 ~ 002）
