> 来源：T15 端到端验收节点 5 测试总结（BUG-T15-001~014 全部闭环后输出）

## 一、部署硬约束（上线前置检查，必须先满足）

| # | 约束项 | 原因 | 检查方式 | 不满足的后果 |
|---|---|---|---|---|
| H-1 | uvicorn **单 worker**（或网关层 sticky session） | `_controls` 为进程内注册表，cancel/resume API 必须命中执行所在进程 | 启动命令确认 `--workers 1`；多实例时确认网关会话亲和配置 | cancel/resume 404/失效，HITL 无法恢复 |
| H-2 | **Redis 启用**（分布式并发槽 + TTL） | 进程内 `_mem_conc` 无 TTL，进程异常退出即槽泄漏 | 配置项检查 + 启动日志确认 Redis 连接成功 | 并发槽泄漏，单用户永久 42901（BUG-012 类复发） |
| H-3 | 网关/LB 空闲超时 **≥ 30s** | SSE 心跳帧 15s 间隔，需留一倍余量防误杀长连接 | 网关配置检查；用 HITL 长暂停用例实测 60s 不断连 | SSE 被中间层静默断开，触发自愈误判 |

## 三、监控配置项（告警规则）

| # | 监控项 | 信号源 | 采集方式 | 告警阈值 | 级别 | 处置动作 | 溯源缺陷 |
|---|---|---|---|---|---|---|---|
| M-1 | 执行僵尸巡检 | DB `workflow_execution` | 定时扫描（5min/次） | `status ∈ (running, paused)` 且 `updated_at` 超 30min（dry-run 场景） | **P0** | 自动调用 `_force_finalize` 路径对应管理接口强制收尾 + 告警人工介入 | BUG-012/014 泄漏的最终兜底网 |
| M-2 | 并发槽占用时长 | 槽位获取时间戳（Redis key TTL/记录） | 定时扫描（5min/次） | dry-run 槽占用 > 10min | P1 | 告警 + 关联执行实例排查是否卡死 | 泄漏早期信号，先于 429 |
| M-3 | 并发拒绝率 | 42901 `item=concurrency` 日志 | 日志聚合统计 | 单用户 1h 内 > 5 次 | P2 | 区分真实并发需求与泄漏；伴随 M-1/M-2 异常则升级为泄漏排查 | BUG-012 |
| M-4 | 保底强制收尾触发 | `_force_finalize` WARNING 日志 | 日志匹配告警 | **出现即告警** | **P1** | 必查：保底触发 = 协作路径失效，检查网关/代理取消传播 | BUG-014 |
| M-5 | R-1 审计占比 | 「执行结束 status=cancelled」且 `tokens IS NULL` | 日志/DB 日报统计 | 占 cancelled 总量比例环比突增 > 20pp | P2 | tokens=NULL 判别强杀路径；占比突增说明断开场景协作唤醒退化面扩大，复查网关/代理层取消传播 | BUG-014 遗留 R-1 |
| M-6 | HITL 超时推进偏差 | `handle_hitl` 超时日志时间 vs deadline | 日志比对 | 偏差 > 5s | P1 | BUG-013 类 DB race 复发信号，检查 paused 落库后台 task | BUG-013 |
| M-7 | 结算保护触发 | 「节点结算超时/失败」ERROR 日志 | 日志匹配告警 | 出现即告警 | P2 | DB 间歇性挂起信号；检查 DB 连接池与慢查询 | BUG-013 |
| M-8 | SSE 断开自愈时延 | `run_paused` → `cancelled` 时差（断开场景） | 日志时序统计 | P95 > 3s | P1 | BUG-014 v2 核心指标（验收实测 0.08s）；退化说明 finally 自愈路径异常 | BUG-014 |
| M-9 | 配额对账差异 | `quota_hold` 与 execution 终态对账 | 每日定时任务 | 差异 > 0 | P1 | R-09 预占/释放闭环校验失败，人工对账并补齐释放 | 配额体系 |
| M-10 | Trace seq 单调性 | trace API 抽检（每日抽样执行实例） | 定时抽检 | 乱序即告警 | P2 | AC-15 回归哨兵，检查 TraceWriter 批量缓冲乱序 | AC-15 |

**告警级别定义**：
- P0：用户不可用 / 资源泄漏进行中 → 立即响应，30min 未定位即回退灰度
- P1：核心链路异常信号 → 当日响应，阻断灰度晋级
- P2：劣化趋势信号 → 纳入日报，连续 3 日异常升级 P1
