## 1. 需求摘要（溯源 PRD v1.0）

### 1.1 业务目标

| 编号 | 目标 | 架构关注点 |
|---|---|---|
| G1 | 用户独立完成"搭—测—发—用"闭环 | 编辑态/运行态分离、Schema 统一 |
| G2 | 双主体数据严格隔离 | 全链路 `owner_type+owner_id` 过滤 |
| G3 | 仅可用授权资源 | 资源授权模型 + 服务层强校验 |
| G4 | 成本可控，超限前置阻断 | 用户维度计量 + 预估拦截 |
| G5 | 高风险节点默认不可用 | 节点能力开关矩阵 |

### 1.2 本期功能范围（P0）

| 阶段 | 范围 | 架构交付面 |
|---|---|---|
| P0-1 | 双主体归属与鉴权、用户域执行上下文、配额计量与阻断 | 数据模型扩展、鉴权中间件、配额服务 |
| P0-2 | 用户侧 VueFlow 画布 | 统一图 Schema v2、前端校验规则引擎 |
| P0-3 | 10 类节点面板、资源选择器、发布与站内对话 | 节点白名单、发布版本模型、对话入口 |

### 1.3 核心实体（初始识别，节点 2 细化）

| 域 | 实体 | 来源 |
|---|---|---|
| 主体域 | Customer、User、Role、MembershipLevel（已有）/ QuotaPlan、IdentityLink、CustomerOrganization（新增） | A1/A4/A7/Q-H |
| 工作流域 | Workflow、WorkflowVersion（新增）、Execution、Checkpoint、TraceEvent | PRD 4.7/4.9/6.5 |
| 资源域 | RAGKnowledgeBase、RAGDocument、LLMModel、Tool、ResourceGrant（新增） | PRD 7.2 |
| 配额域 | QuotaAccount、UsageRecord（新增） | PRD 7.3 |
| 交付域 | Agent（已发布形态）、Conversation、Message | PRD 6.4 |

### 1.4 核心数据流

| 流 | 路径 | 关键约束 |
|---|---|---|
| 编辑流 | 画布拖拽 → 草稿自动保存 → 全量校验 → 发布不可变版本 | Schema v2；发布绑定快照 |
| 执行流 | 触发 → 归属鉴权 → 配额预估 → 引擎执行 → SSE 流式 → 计量结算 → Trace 落库 | 预估先于调用；版本锁定 |
| RAG 流 | 文档上传 → 解析切分 → 向量化（Qdrant）→ 检索召回 → 重排 → 引用输出 | 归属过滤在召回前注入 |
| 授权流 | 管理员配置授权 → 白名单生效 → 用户选择器仅见授权项 | 服务端二次校验 |

## 2. 显性约束（PRD 与已确认决策直接导出）

| 编号 | 约束 | 来源 | 架构影响 |
|---|---|---|---|
| C-01 | 双主体隔离：`cus`/`usr`，后台用户叠加 `data_scope` | A1/Q1 | 所有查询路径必须携带双过滤条件 |
| C-02 | 同一执行引擎复用，禁止复制引擎 | 路线结论 | 执行器改造为"引擎 + 域上下文"模式 |
| C-03 | 前后台双画布，Schema 必须统一并兼容 | A5 | Schema 版本治理 + v1→v2 转换器 |
| C-04 | 代码节点用户侧永久关闭；HTTP 走域名白名单 | RK-03 | 节点能力开关按域生效 |
| C-05 | 配额超限在模型调用前拦截 | G4/AC-11 | token 预估机制与原子扣减 |
| C-06 | token `typ`/`sub` 同源（已修复 RK-13） | D3 | 下游归属判断可信任 `actor` |
| C-07 | 关联需用户主动确认+验证，禁止自动绑定 | 3.3/RK-14 | 现有自动关联逻辑必须下线 |
| C-08 | 编辑态/运行态严格分离，运行绑定发布版本 | 4.8/RK-07 | 执行实例绑定 version 快照 |
| C-09 | 首期仅站内对话，无开放 API | A6 | 不设计 API Key 体系 |
| C-10 | 敏感字段打码、密钥不导出 | 4.9/7.4 | 凭证托管在平台侧 |

## 3. 隐性约束（代码与基础设施核查导出）

| 编号 | 事实 | 依据 | 架构影响 |
|---|---|---|---|
| C-11 | PostgreSQL + Tortoise ORM，连接池 5–20 | config.conf `[db]` | HITL 等待不得占用连接；长事务禁止 |
| C-12 | Redis 已确认启用（Q-G） | config.conf `[redis]` | 配额计数、限流、幂等键、分布式锁走 Redis |
| C-13 | RabbitMQ 已启用（event bus + DLQ，prefetch=10） | config.conf `[rabbitmq]` | 异步事件有底座；P0 执行不走 MQ（Q-E） |
| C-14 | 向量存储统一 Qdrant（Q-B），pgvector 路径废弃 | Q-B 决策 | 归属隔离=知识库级 collection + 服务层强校验 |
| C-15 | RAG 知识库归属改多态（Q-A）：`owner_type+owner_id` 替代 `created_by` 语义 | Q-A 决策 | 放弃 DB 级 FK，服务层校验 + 审计补偿 |
| C-16 | 会员体系已存在：`MembershipLevel.level_type`（regular/vip/svip）+ 过期态 | customer_membership 模型 | 客户配额来源映射 `level_type` → QuotaPlan |
| C-17 | 统一 QuotaPlan 实体（Q-D），客户会员等级与后台角色双向映射 | Q-D 决策 | 配额项集合一份定义 |
| C-18 | VueFlow 锁定 `@vue-flow/core ^1.48.2`（现有依赖） | web/package.json | 用户侧画布同版本，不升级 |
| C-19 | 审计已启用（90 天），Prometheus 已启用，Jaeger/ELK 禁用 | config.conf | 复用现有通道，不建分布式追踪 |
| C-20 | 私有化部署 + openGauss 必须兼容（Q-I） | Q-I 决策 | SQL 避免 PG 专有语法；节点 3 出兼容清单 |
| C-21 | Tortoise 不支持运行时热注册模型 | project memory | 新增模型随启动迁移注册，与插件开关解耦 |
| C-22 | 执行器进程内运行（Q-E 确认保留 + 预留 MQ 抽象） | Q-E 决策 | 并发上限受单进程约束，信号量限流 |
| C-23 | 客户侧 P0 需组织模型（Q-H）：组织/成员/角色，仅用于 HITL 审批人范围与协作可见性 | Q-H 决策 | **不引入组织级配额**，配额仍按个人；不复用后台 Department |

## 4. 非功能需求清单（Q-F 已确认默认值）

| 类别 | 指标 | 确认值 |
|---|---|---|
| 并发 | 全局同时执行工作流数 | 50 |
| 并发 | 单用户并发执行 | 3（按套餐可调） |
| 并发 | SSE 同时在线连接 | 200 |
| 延迟 | 引擎调度开销（不含 LLM） | P95 < 200ms/节点 |
| 延迟 | SSE 首 token 透传附加延迟 | < 500ms |
| 数据量 | 单用户工作流数 / 单图节点数 | ≤ 50 / ≤ 200 |
| 数据量 | 单用户知识库 chunk 量 | ≤ 10 万（默认，按套餐） |
| 数据量 | Trace 事件量 / 保留 | ≤ 5000 事件/次；用户可见 30 天 |
| 可用性 | 单实例无 HA；执行中断检查点恢复率 | 100% |
| 可观测 | 指标：节点耗时、token、失败率、召回空率 | Prometheus 现有通道 |
| 兼容性 | 存量 v1 图在新引擎可运行 | 转换器 100% 通过 |
| 兼容性 | openGauss 可部署 | 必须通过部署测试 |
| 成本 | token 预估偏差 | ±20% 以内，超出走结算补扣 |
| 安全 | 越权用例拦截率 | 100%（AC-09/AC-10） |
| 隐私 | 账号注销处置（Q-J） | 记忆/文件/会话硬删除；工作流与 Trace 匿名化；配额记录保留对账 |
