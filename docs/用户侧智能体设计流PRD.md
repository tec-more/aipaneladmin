## 0. 文档信息

### 0.1 术语

| 术语 | 定义 |
|---|---|
| 工作流（Workflow） | 由节点与边构成的有向无环图（DAG），可在发布后被运行 |
| 智能体（Agent） | 工作流的可交付形态：带入口、权限、配额与使用界面 |
| 模板 | 管理员发布的可复制工作流基线，用户复制后成为自己的私有工作流 |
| 端口（Handle） | 节点上的输入/输出锚点，携带变量类型 |
| 运行态（Run Mode） | 画布只读并叠加执行进度、耗时、Trace 的状态 |
| 编辑态（Edit Mode） | 拖拽、连线、配置、校验的状态 |
| 引用（Citation） | RAG 输出中被引用的原文片段及来源元数据 |

## 1. 路线结论

**结论：采用“同一执行引擎 + 插件内纵向分域 + 用户侧独立 VueFlow 画布”。**

| 方案 | 结论 | 理由 |
|---|---|---|
| 直接放开后台模块 | 否决 | 无归属隔离、无用户配额、`code`/`http` 节点等于开放代码执行与内网访问 |
| 新建独立模块并复制执行引擎 | 否决 | 双引擎长期维护、节点语义漂移、缺陷需双处修复 |
| **同插件纵向分域（采纳）** | 采纳 | 复用 LangGraph 执行、SSE、检查点、记忆；隔离在数据层与服务层实现；画布新建以匹配 C 端交互 |

### 1.1 复用边界（必须写进研发排期）

| 能力 | 复用 | 新建/改造 |
|---|---|---|
| 图执行调度（DAG、条件、循环、并行） | 复用 | 增加用户域执行上下文与归属校验 |
| 节点执行实现（LLM/技能/工具/HTTP/代码等） | 复用 | 按用户域裁剪与沙箱化 |
| 流式输出与取消 | 复用 | 增加按用户的并发与取消权限校验 |
| 检查点/会话线程 | 复用 | 线程 ID 绑定 `customer_id`，禁止跨用户续跑 |
| 记忆能力 | 复用 | 已支持 `customer_id`，补充读写校验 |
| 数据模型 | — | 新增归属、可见性、版本、发布态 |
| 画布编辑器 | — | 用户侧全新 VueFlow 编辑器（独立 Schema 版本号） |
| 资源授权与配额 | — | 新建资源白名单、用户计量、超限阻断 |

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 | 分类 | 度量 |
|---|---|---|---|
| G1 | 注册用户可独立完成“搭—测—发—用”闭环 | 【画布交互】 | 新用户 30 分钟内从模板到发布成功 |
| G2 | 用户数据与资源严格隔离，零跨主体泄露（客户/后台普通用户） | 【执行引擎】 | 越权访问用例 100% 拦截 |
| G3 | 用户只能使用被授权的模型、知识库、工具 | 【AI 能力】 | 未授权资源在面板不可见、接口拒绝 |
| G4 | 成本可控，超限前置阻断 | 【执行引擎】 | 超额请求在调用模型前被拒绝 |
| G5 | 高风险节点默认不可用 | 【执行引擎】 | 默认策略下用户无法配置代码执行与任意外网访问 |

### 2.2 非目标

- 不在本期统一后台与用户侧编辑器（见 A5）。
- 不定义具体模型厂商、向量库厂商的选型（仅定义能力契约与取舍维度）。
- 不提供多用户实时协同编辑（本期仅单用户编辑 + 版本锁）。
- 不提供用户自定义代码插件市场。

## 3. 角色与权限

| 角色 | 定义 | 关键权限 |
|---|---|---|
| 平台管理员 | 后台管理员 | 节点能力开关、资源授权、模板发布、配额策略、审计 |
| 客户用户（注册用户） | 用户侧站点注册的终端客户，`typ=cus` | 创建/编辑/测试/发布自有工作流，使用授权资源，按会员等级取额度 |
| 后台普通用户 | 后台账号但非管理员，`typ=usr` | 同客户用户，但资源可见性叠加角色数据权限，按角色套餐取额度 |
| 运营/审核 | 可选角色 | 模板审核、公开智能体审核、违规下架 |

### 3.1 权限矩阵（产品级）

| 能力 | 管理员 | 客户用户 | 后台普通用户 | 说明 |
|---|---|---|---|---|
| 创建空白工作流 | 是 | 是 | 是 | 空白创建 + 仅授权节点/资源（A3） |
| 复制模板 | 是 | 是 | 是 | 复制后归属当前主体 |
| 编辑他人工作流 | 是 | 否 | 否 | 仅可读取已发布的公开智能体 |
| 跨主体访问资源 | 是（审计） | 否 | 否 | 不得以任何接口绕过归属过滤 |
| 使用平台模型 | 配置 | 仅授权清单 | 仅授权清单 + 角色数据范围 | 【AI 能力】 |
| 使用私有知识库 | 是 | 是（自建，受配额） | 是（自建，受配额） | 跨主体不可见 |
| 使用公共知识库 | 是 | 按授权 | 按授权 + 数据范围 | 管理员控制可见范围 |
| 使用代码/HTTP/工具节点 | 是 | 默认否，按白名单 | 默认否，按白名单 + 角色 | 【执行引擎】 |
| 发布为智能体 | 是 | 是 | 是 | 需通过发布校验 |
| 配置 HITL 审批人 | 是 | 仅本人或同组织成员 | 仅本人或同组织成员 | 见 5.9 约束 |

### 3.2 双身份处理规则（L1 身份关联）

| 编号 | 规则 |
|---|---|
| D1 | 一个自然人最多关联 1 个客户主体与 1 个后台主体，映射关系唯一 |
| D2 | 绑定仅允许由用户主动发起，或在系统提示下由用户明确选择“关联”；无论哪种方式，都必须完成对方主体验证；系统不得静默完成绑定 |
| D3 | token 的 `typ` 与 `sub` 必须同源：客户主体用 `customer.id`，后台用户用 `user.id`；禁止跨表借用 ID |
| D4 | 同一 token 不跨域；身份切换必须重新登录，切换后按当前主体重新过滤资源与配额 |
| D5 | 资产分别归属各自主体，不复制、不迁移；跨身份使用资源仅可通过白名单共享（本期不提供，见 L2） |
| D6 | 配额、审计、HITL 组织范围一律以当前登录主体为准 |
| D7 | 解绑只解除映射，不删除任何一方资产；解绑后立即失去跨身份识别能力 |
| D8 | 存量数据中按邮箱已自动建立的关联，须按 3.3 的“主动确认 + 验证”重新核对：用户拒绝或验证失败即解除关联，过程留存审计 |

### 3.3 账号关联提示与主动确认规则【执行引擎】

> 系统只负责“发现与提示”，关联动作必须由用户主动选择并完成验证，系统不得自动建立映射。

| 编号 | 规则 |
|---|---|
| L1 | 触发时机：客户首次登录用户侧、后台普通用户首次进入用户侧时，检测同邮箱的“另一主体”；仅在检测到且未关联时提示，不阻断主流程 |
| L2 | 提示形态：非阻塞提示卡（页面顶部或账号设置引导）；默认焦点按钮为“暂不关联”，避免误点 |
| L3 | 展示内容仅限脱敏信息：主体类型、用户名、打码邮箱、最近登录时间；不得展示资产名称、数量、金额等业务数据 |
| L4 | 用户选项：立即关联 / 暂不关联 / 不再提示。选“暂不关联”仅本次会话不再出现，下次登录仍可提示 |
| L5 | 关联前必须验证对方主体归属：客户→后台用后台密码或邮箱验证码；后台→客户用邮箱验证码（客户已设密码时可改用密码） |
| L6 | 验证失败 3 次锁定 10 分钟并留审计；不得因邮箱相同而跳过验证 |
| L7 | 提示频率：同一对主体 30 天内最多提示 1 次；“不再提示”后永久关闭，仅可在“账号设置—关联管理”手动重新开启 |
| L8 | 关联结果：仅建立映射并展示“已关联”状态；不改变登录方式、不合并资产、不合并配额、双方资产互不可见 |
| L9 | 解绑：在“账号设置—关联管理”发起，需再次验证；解绑后进入 30 天冷却期，不立即再次提示 |
| L10 | 审计：提示展示、跳过、不再提示、发起关联、验证失败、关联成功、解绑均记录主体、时间、IP、结果，用户可查 |

**关联管理页（产品定义）**

| 区块 | 内容 |
|---|---|
| 状态 | 未关联 / 已关联（显示对方主体类型与关联时间）/ 冷却中 |
| 操作 | 关联账号 / 解除关联 / 重新开启提示 |
| 说明 | 明示“关联仅用于身份识别，不共享工作流、知识库、额度与账单” |

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 对方已关联其他账号 | 对方主体已存在映射 | 提示“该账号已关联其他用户”，给客服入口 | 联系客服处理 |
| 对方主体被禁用 | 对方账号不活跃 | 提示不可关联，不透露禁用细节 | 联系管理员 |
| 验证次数耗尽 | 连续失败 3 次 | 锁定 10 分钟并提示剩余时间 | 稍后重试 |
| 重复绑定 | 已关联状态下再次发起 | 提示“已关联”，展示关联时间 | 查看关联管理页 |
| 提示被关闭后想恢复 | 用户改主意 | 设置页可重新开启，30 天冷却期内不弹窗 | 在关联管理页开启 |

## 4. 画布数据模型（产品级定义）

### 4.1 图结构

| 对象 | 关键属性 | 规则 |
|---|---|---|
| 图（Graph） | schema_version、workflow_id、version、nodes、edges、variables、settings | Schema 版本必须显式声明 |
| 节点（Node） | id、type、type_version、label、position、config、ports、error_strategy | id 全局唯一且不可复用 |
| 边（Edge） | id、source_node、source_handle、target_node、target_handle、condition | 一条边只能连接一个输出端口与一个输入端口 |
| 端口（Handle） | id、direction（in/out）、data_type、required、multiplicity、description | 端口类型参与连线校验 |
| 变量（Variable） | name、type、scope、default、sensitive、description | 变量名唯一，敏感变量禁止导出明文 |

### 4.2 类型系统【画布交互】

| 类型 | 说明 | 典型来源 |
|---|---|---|
| `string` | 文本 | 触发输入、LLM 文本输出 |
| `number` / `integer` | 数值 / 整数 | 工具返回、计算 |
| `boolean` | 布尔 | 条件结果 |
| `object` | 结构化对象（字段模式由节点声明） | LLM 结构化输出、工具返回 |
| `array<T>` | 同构数组 | 检索片段、循环输入、工具批量结果 |
| `file` | 文件引用 | 用户上传 |
| `image` | 图片引用 | 多模态输入/输出 |
| `message[]` | 对话消息序列 | 会话上下文 |
| `document` | 文档对象（含解析状态） | 文档解析结果 |
| `chunk[]` | 检索片段集合（含分数、来源） | RAG / 向量检索 |
| `any` | 任意类型（仅允许作为“透传”通道） | 通用汇聚 |
| `unknown` | 未推断类型（发布前必须收敛） | 未连接/未配置 |

### 4.3 类型兼容矩阵【画布交互】

| 源 → 目标 | 是否允许 | 说明 |
|---|---|---|
| 同类型 → 同类型 | 允许 | 基础 |
| `integer` → `number` | 允许 | 数值加宽 |
| `number` → `integer` | 禁止 | 需显式转换节点 |
| 任意类型 → `any` | 允许 | 仅透传，不做隐式转换 |
| `any` → 具体类型 | 禁止 | 必须显式声明或经转换节点 |
| `string` → `number` / `boolean` | 禁止 | 避免隐式解析歧义 |
| `array<T>` → `array<any>` | 允许 | 逐项保留原类型 |
| `object` → `string` | 禁止 | 需模板节点显式序列化 |
| `unknown` → 任意 | 禁止 | 必须先完成上游配置并推断类型 |
| 敏感类型（文件/图片）→ `string` | 禁止 | 仅允许引用传递 |

### 4.4 端口基数规则【画布交互】

| 规则 | 说明 |
|---|---|
| 输出端口可扇出 | 一个输出可连多条边，无数量限制 |
| 输入端口单入 | 默认最多 1 条入边；声明 `multiplicity=multi` 的端口（如汇聚节点）可多入 |
| 禁止自连 | 节点不能连接自身 |
| 禁止重复边 | 同一 source_handle → target_handle 只允许一条 |
| 条件分支端口 | 每个分支端口至多 1 条出边；`else` 端口必须存在且必连 |
| 循环容器端口 | 容器内节点不可直接连到容器外；跨界必须经容器出入口 |

### 4.5 连线合法性校验（错误码清单）【画布交互】

| 错误码 | 场景 | 提示文案要求 | 阻断级别 |
|---|---|---|---|
| E-101 | 类型不兼容 | 指明“源类型 → 目标类型”及建议转换节点 | 阻断连线 |
| E-102 | 必填输入未连接 | 指明节点与端口名 | 阻断发布 |
| E-103 | 形成环（非循环容器内） | 高亮成环路径 | 阻断连线 |
| E-104 | 重复连线 | 提示已有连线 | 阻断连线 |
| E-105 | 输入端已占用 | 提示可先删除原连线 | 阻断连线 |
| E-106 | 输出端口悬空 | 警告（可发布前统一检查） | 阻断发布 |
| E-107 | 引用了未声明变量 | 指明变量名与所在节点 | 阻断发布 |
| E-108 | 子工作流版本失效/被删除 | 指明子工作流与版本 | 阻断发布 |
| E-109 | 使用了未授权节点类型 | 提示联系管理员开通 | 阻断创建 |
| E-110 | 使用了未授权资源（模型/知识库/工具） | 指明资源名 | 阻断保存 |
| E-111 | 循环缺少退出条件或超出上限 | 指明循环节点 | 阻断发布 |
| E-112 | HITL 未配置审批人或超时策略 | 指明节点 | 阻断发布 |
| E-113 | 运行期配额超限 | 显示剩余额度与重置时间 | 阻断运行 |

### 4.6 自动布局【画布交互】

- 布局算法：层次布局（自上而下），按连接深度分层，同层水平均分。
- 触发时机：手动点击“整理布局”；新建时对已导入图自动布局一次。
- 约束：保留用户手动位置；布局后可撤销；循环容器内子图独立布局。
- 布局不得改变拓扑、连线与端口，仅改变坐标。

### 4.7 画布状态管理【画布交互】

| 状态 | 内容 | 持久化 |
|---|---|---|
| 编辑草稿 | 图数据、变量表、面板配置 | 自动保存（防抖），与发布版本分离 |
| 发布版本 | 不可变快照 | 版本号 + 发布人 + 时间 |
| 选择态 | 选中节点、选中边、多选集合 | 不持久化 |
| 视口 | 缩放、平移 | 按用户记忆 |
| 历史栈 | 撤销/重做（至少 50 步） | 会话内 |
| 校验态 | 错误列表、错误定位 | 随草稿 |
| 运行态 | 执行实例、进度、Trace | 服务端执行实例 |

### 4.8 编辑态 / 运行态边界【画布交互】

| 能力 | 编辑态 | 运行态 |
|---|---|---|
| 拖拽/连线/删除节点 | 允许 | 禁止（只读） |
| 修改节点配置 | 允许 | 禁止 |
| 查看节点输入输出 | 仅结构预览 | 展示真实值（敏感字段打码） |
| 执行 | 支持单节点试跑与整图试跑 | 支持再次运行、取消、重跑失败节点 |
| 布局 | 允许 | 允许（仅视图，不影响执行） |
| 版本 | 草稿 | 绑定具体发布版本 |

- 切换规则：运行态进入需基于“已保存草稿”或“指定发布版本”；运行中禁止切换版本，避免图与执行不一致。
- 运行态画布必须显著标识“只读”。

### 4.9 版本与 JSON 导出规范【画布交互】

| 项 | 规范 |
|---|---|
| 导出内容 | schema_version、workflow 元信息、nodes、edges、variables、settings、导出时间 |
| 不含内容 | 密钥、模型凭证、用户隐私字段、运行数据、Trace |
| 导入校验 | 版本兼容、节点类型可用性、端口与类型合法性、资源可用性、配额可承载 |
| 版本兼容 | 向后兼容读取；不兼容时给出“升级工具”提示，不静默降级 |
| 版本号 | 发布序号自增；导出文件名包含名称与版本 |
| 归属 | 导入后归属当前用户，原归属不继承 |

### 5.1 触发节点（Start / Trigger）

| 项 | 内容 |
|---|---|

| 数量约束 | 每个工作流有且仅 1 个触发节点 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 无输入 | in | — | — | 不允许配置入边 |
| `user_input` | out | string | 是 | 用户本轮输入文本 |
| `attachments` | out | array<file> | 否 | 附件列表，受配额与类型白名单约束 |
| `session_id` | out | string | 是 | 会话标识，引擎生成 |
| `user_profile` | out | object | 否 | 会员等级、昵称等非敏感画像字段 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| input_schema | array<object> | 否 | 单字段文本 | 声明入口表单字段、类型、是否必填 |
| entry_mode | enum | 是 | `chat` | `chat` / `form` / `api`（按套餐开放） |
| welcome_text | string | 否 | 空 | ≤ 500 字符 |
| suggested_questions | array<string> | 否 | 空 | ≤ 5 条 |
| file_accept | array<string> | 否 | 空 | 受平台文件类型白名单限制 |
| max_file_size_mb | integer | 否 | 受平台限制 | 用户不可突破平台上限 |

**数据流转**：入口输入 → 触发节点输出 → 下游节点引用 `{{trigger.user_input}}` 等；会话级字段（`session_id`、`user_profile`）不可被下游覆盖。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 输入缺失 | 必填字段为空 | 入口前置校验提示 | 补全后重试 |
| 附件超限 | 数量/大小/类型不符合 | 拒绝上传并说明具体原因 | 调整附件 |
| 入口未发布 | 未发布即尝试对话入口 | 提示“未发布” | 先发布 |
| 会话失效 | 会话过期 | 重新建立会话，历史按保留策略处理 | 重新发送 |

### 5.2 LLM 节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 调用已授权大模型完成生成、改写、抽取、判定 |
| 模型来源 | 仅可选择管理员授权给当前用户/套餐的模型（不指定厂商） |
| 输入组装 | 系统提示词 + 会话历史 + 变量插值 + 检索片段 + 结构化输出约束 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `prompt_vars` | in | object | 否 | 模板变量集合，键名需与提示词占位符一致 |
| `context` | in | chunk[] | 否 | 检索片段，注入为引用块 |
| `history` | in | message[] | 否 | 会话历史，受上下文预算裁剪 |
| `text` | out | string | 是 | 文本结果 |
| `structured` | out | object | 否 | 结构化结果（声明 schema 时） |
| `usage` | out | object{tokens_in,tokens_out,cost} | 是 | 计量信息，用于配额与审计 |
| `raw` | out | object | 否 | 原始响应（敏感字段打码） |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| model_ref | string | 是 | 授权清单首项 | 必须属于授权清单，否则 E-110 |
| system_prompt | string | 否 | 空 | 支持变量插值；≤ 8000 字符 |
| user_prompt | string | 是 | — | 支持变量插值；必须至少引用一个输入或常量 |
| history_mode | enum | 是 | `last_n` | `none` / `last_n` / `summary` |
| history_turns | integer | 否 | 6 | 1–50；受上下文预算二次裁剪 |
| temperature | number | 否 | 0.3 | 0–2；结构化输出建议 ≤ 0.5 |
| max_output_tokens | integer | 否 | 按模型上限 | 不得超过套餐上限 |
| output_mode | enum | 是 | `text` | `text` / `json_object` / `json_schema` |
| output_schema | object | 条件必填 | 空 | `json_schema` 必填；不支持时降级为 `json_object` 并提示 |
| stream | boolean | 是 | true | 关闭后一次性返回 |
| stop | array<string> | 否 | 空 | ≤ 4 条 |
| citation_required | boolean | 否 | false | 开启后无引用时标记“未溯源” |
| fallback_model_ref | string | 否 | 空 | 主模型失败时的备用模型（须已授权） |

**数据流转**：上游变量 → 提示词渲染 → 上下文预算裁剪（超限时先裁历史、再裁检索片段、最后报错）→ 模型调用 → 流式输出与结构化解析 → `usage` 上报计量。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 模型未授权 | 引用了不可用模型 | 保存时阻断 | 更换模型 |
| 配额不足 | 预估或实际超限 | 运行前阻断，展示剩余额度 | 等待重置或升级套餐 |
| 上下文超限 | 输入超出预算 | 提示可裁剪项与建议值 | 减少历史轮数/检索条数 |
| 结构化解析失败 | 输出不符合 schema | 按策略重试 1 次，仍失败走错误端口 | 降低温度/简化 schema |
| 模型超时/限流 | 上游返回超时或限流 | 指数退避重试，超限失败 | 稍后重试或切换备用模型 |
| 内容被拦截 | 触发安全策略 | 返回统一安全提示，不展示原始内容 | 调整输入 |
| 无引用 | 开启引用必填但无片段 | 输出标记“未溯源”并告警 | 补充知识库或关闭该要求 |

### 5.3 RAG 检索节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 面向已授权知识库完成“查询理解 → 召回 → 重排 → 片段输出与溯源” |
| 与向量库节点区别 | RAG 节点是完整链路（含解析、切分、引用）；向量库节点是底层向量读写 |
| 知识库范围 | 用户私有知识库 + 管理员授权的公共知识库 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `query` | in | string | 是 | 检索问题，可来自用户或上游改写 |
| `filters` | in | object | 否 | 元数据过滤（标签、时间、来源） |
| `chunks` | out | chunk[] | 是 | 片段集合（内容、分数、来源、页码） |
| `citations` | out | array<object> | 是 | 引用列表，供展示与审计 |
| `empty` | out | boolean | 是 | 是否空召回，用于接条件分支兜底 |
| `stats` | out | object{recall,rerank_ms} | 否 | 检索诊断信息（不含原文） |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| knowledge_base_refs | array<string> | 是 | — | ≥1；必须在授权范围内 |
| top_k | integer | 是 | 8 | 1–50；受套餐上限约束 |
| score_threshold | number | 否 | 0.2 | 0–1；为空则不过滤 |
| rerank_enabled | boolean | 是 | true | 关闭需提示效果影响 |
| rerank_top_n | integer | 否 | 4 | ≤ top_k |
| query_rewrite | enum | 是 | `off` | `off` / `expand` / `hyde`；开启计入额外 token |
| metadata_filter_mode | enum | 是 | `merge` | `merge`（与外部 filters 合并）/ `override` |
| citation_required | boolean | 是 | true | 关闭则输出不含来源 |
| empty_strategy | enum | 是 | `return_empty` | `return_empty` / `error` / `fallback_message` |
| max_context_tokens | integer | 否 | 2000 | 超限按分数截断 |

**数据流转**：查询 → 改写（可选）→ 向量召回 → 重排 → 分数阈值过滤 → 上下文预算截断 → 片段与引用输出；空召回按策略走兜底分支。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 知识库未授权/被删除 | 引用失效 | 保存阻断；运行时 E-110 | 更换知识库 |
| 知识库未就绪 | 文档解析/向量化未完成 | 节点返回“未就绪”，不返回半成品片段 | 等待就绪或选择其他库 |
| 空召回 | 无满足阈值结果 | `empty=true`，按策略提示或兜底 | 放宽阈值/补充文档 |
| 检索超时 | 超过节点超时 | 错误端口或失败提示 | 降低 top_k/关闭重排 |
| 上下文超限 | 片段总 token 超预算 | 自动截断并在结果中标记 | 调整 top_k 或片段长度 |
| 引用缺失 | 开启必填但无来源 | 结果标记“未溯源” | 检查知识库元数据完整性 |

### 5.4 向量库节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 对用户可见的向量集合执行写入、更新、删除、相似度查询等底层操作 |
| 使用定位 | 高级节点，默认仅对通过引导的用户开放；普通用户优先用 RAG 节点 |
| 能力契约 | 只定义能力（维度一致性、距离度量、元数据过滤、批量上限），选型不在本文范围 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `records` | in | array<object> | 条件必填 | 写入/更新时必填（id、文本、元数据） |
| `query_vector_source` | in | array<number> \| string | 条件必填 | 查询时必填：向量或待向量化文本 |
| `result` | out | object{affected, ids} | 是 | 写操作结果 |
| `matches` | out | array<object{id,score,metadata}> | 是 | 查询结果 |
| `success` | out | boolean | 是 | 供条件分支判断 |

**配置字段 Schema**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| collection_ref | string | 是 | — | 仅用户可见集合；公共集合只读 |
| operation | enum | 是 | `query` | `upsert` / `update` / `delete` / `query` |
| embedding_mode | enum | 是 | `platform` | `platform`（平台授权模型）/ `precomputed`（外部向量） |
| dimension | integer | 条件必填 | — | 预计算必填；必须与集合一致，否则拒绝 |
| metric | enum | 否 | 集合默认 | 与集合不一致时报错 |
| top_k | integer | 条件必填 | 5 | 查询时必填，受套餐上限 |
| metadata_filter | object | 否 | 空 | 仅允许白名单字段 |
| batch_size | integer | 否 | 100 | ≤ 平台上限 |
| on_conflict | enum | 否 | `skip` | `skip` / `overwrite` |
| writeback_dry_run | boolean | 否 | false | 开启仅校验不写入 |

**数据流转**：输入记录 → 维度/权限/配额校验 → 分批写入或查询 → 返回结果；写入类操作必须产生审计记录（谁写入、多少条）。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 维度不一致 | 向量维度与集合不符 | 明确报出期望与实际维度 | 修正向量或改用平台向量化 |
| 只读集合被写 | 对公共集合执行写操作 | 拒绝并说明只读 | 复制为私有集合 |
| 批量超限 | 单次条数超上限 | 提示分批 | 减小 batch_size |
| 配额不足 | 写入量超出套餐配额 | 运行前阻断 | 减少条数或升级 |
| 部分失败 | 批次内个别记录失败 | 返回失败明细，不整体回滚（除显式事务模式） | 修正失败记录重试 |
| 集合不存在 | 引用失效 | 阻断保存/运行 | 重新选择集合 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |

| param_mapping | object | 是 | — | 逐字段映射，缺必填参数阻断保存 |
| timeout_ms | integer | 否 | 工具默认 | 不得高于平台上限 |
| retry | object{max,backoff} | 否 | 0 | 仅工具声明幂等时允许 |
| result_max_kb | integer | 否 | 64 | 超出截断并标记 |
| fallback_value | object | 否 | 空 | 策略 `continue_with_default` 时必填 |
| mask_fields | array<string> | 否 | 空 | 结果中需打码字段 |

**数据流转**：参数映射 → 参数校验 → 调用（带超时）→ 结果裁剪 → 打码 → 输出；调用记录进入审计（工具、耗时、结果状态，不含敏感原文）。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 未授权工具 | 引用不可用工具 | 保存阻断（E-110） | 更换工具 |
| 参数缺失/类型不符 | 映射不完整 | 保存与运行双重校验提示 | 补全映射 |
| 鉴权失效 | 平台凭证过期 | 统一提示“工具暂不可用”，不暴露细节 | 联系管理员 |
| 超时/限流 | 超出超时或频控 | 重试后失败，走错误端口 | 降低频率 |
| 返回过大 | 超结果上限 | 截断并标记 | 调整工具或分页 |
| 工具下线 | 工具被管理员禁用 | 运行前阻断 | 更换工具 |

### 5.6 条件分支节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 基于变量与规则选择执行路径 |
| 分支形式 | 简单二分支（真/假）与多分支（case + else） |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `input` | in | any | 是 | 待判定对象 |
| `true` / `false` | out | any | 是 | 二分支模式 |
| `case_1..n` / `else` | out | any | 是 | 多分支模式；`else` 必连 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| mode | enum | 是 | `binary` | `binary` / `multi_case` |
| logic | enum | 是 | `all` | `all` / `any`（多条件组合） |
| rules | array<object{field,operator,value}> | 是 | 空 | ≥1；字段必须来自已声明变量 |
| operators | enum | — | — | 等于/不等于/包含/不包含/大于/小于/为空/不为空/正则匹配 |
| case_count | integer | 否 | 0 | 1–10（多分支） |
| default_branch | string | 是 | `else` | 不可删除 |

**数据流转**：输入取字段 → 规则求值 → 命中分支 → 仅该分支下游执行；未命中走 `else`；求值异常按错误策略处理。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 字段不存在 | 引用未声明或上游未输出 | 运行前校验阻断 | 修正字段引用 |
| 类型不可比 | 例如字符串与数值比较 | 保存阻断并提示 | 显式转换 |
| 正则非法 | 正则语法错误 | 保存阻断 | 修正表达式 |
| 无命中分支 | 多分支均不满足 | 走 `else`；无 `else` 则阻断保存 | 配置 `else` |
| 分支不可达 | 静态分析发现某分支永不命中 | 警告（不阻断） | 调整规则 |

### 5.7 循环节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 对数组逐项处理，或满足条件时重复执行子图 |
| 形态 | 容器节点，内部包含子图 |
| 循环类型 | 固定次数、数组遍历、条件循环 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `items` | in | array<any> | 条件必填 | 数组遍历时必填 |
| `body_in` | in | any | 是 | 容器入口 |
| `body_out` | out | any | 是 | 容器出口 |
| `item` | out | any | 是 | 当前项（遍历模式） |
| `index` | out | integer | 是 | 当前下标，从 0 开始 |
| `results` | out | array<any> | 是 | 汇总结果（按配置聚合） |
| `completed` | out | boolean | 是 | 循环正常结束标记 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| loop_type | enum | 是 | `array` | `fixed` / `array` / `while` |
| max_iterations | integer | 是 | 20 | 1–100，且不高于套餐上限 |
| fixed_count | integer | 条件必填 | 1 | `fixed` 时必填 |
| condition | object{field,operator,value} | 条件必填 | 空 | `while` 时必填 |
| break_on_error | boolean | 是 | true | 关闭则记录错误继续 |
| concurrency | integer | 否 | 1 | 1–5；>1 需提示顺序不确定性 |
| aggregation | enum | 是 | `collect` | `collect` / `merge_object` / `first` / `last` |
| item_max_kb | integer | 否 | 64 | 单项过大截断并标记 |

**数据流转**：输入集合或条件 → 逐次执行子图 → 子图输出按聚合策略汇总 → 输出 `results`；`item`/`index` 作用域仅容器内。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 超出最大次数 | 达到 `max_iterations` | 终止循环并告警，输出部分结果 | 调整上限或退出条件 |
| 无退出条件 | `while` 缺条件 | 保存阻断（E-111） | 配置条件 |
| 子图失败 | 内部节点失败且 `break_on_error` | 循环失败并指明失败轮次 | 修复子图或关闭中断 |
| 空集合 | 输入为空数组 | 直接完成，`results=[]`，标记空输入 | 上游补默认值 |
| 并发超限 | 并发高于套餐 | 保存阻断 | 降低并发 |
| 结果过大 | 汇总结果超上限 | 截断并标记 | 减少条数或改聚合方式 |

### 5.8 子工作流节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 复用已发布工作流作为子过程，实现模块化 |
| 可选范围 | 自己的已发布工作流 + 管理员发布的公共子工作流 |
| 版本策略 | 建议锁定版本，避免上游变更导致行为漂移 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `inputs` | in | object | 是 | 必须匹配子工作流输入契约 |
| `outputs` | out | object | 是 | 子工作流输出契约 |
| `status` | out | object{success,code} | 是 | 执行状态 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| workflow_ref | string | 是 | — | 必须已发布且可见 |
| version_policy | enum | 是 | `pinned` | `pinned` / `latest`；`latest` 需提示风险 |
| pinned_version | integer | 条件必填 | — | `pinned` 时必填 |
| input_mapping | object | 是 | — | 契约字段逐一映射 |
| timeout_ms | integer | 否 | 平台默认 | 不得高于平台上限 |
| max_depth | integer | 是 | 3 | 1–5，防止递归嵌套 |
| fail_isolation | enum | 是 | `propagate` | `propagate` / `swallow_with_default` |

**数据流转**：输入映射 → 契约校验 → 子工作流执行（独立执行实例）→ 输出映射 → 返回；子执行计入总配额与审计。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 子工作流未发布/被删 | 引用失效 | 保存或运行前阻断（E-108） | 重新选择 |
| 契约变更 | 输入输出字段不匹配 | 明确缺失/多余字段 | 更新映射或锁定旧版本 |
| 递归超深 | 超出 `max_depth` | 阻断并提示调用链 | 拆分或降低深度 |
| 子流程失败 | 内部失败 | 按隔离策略传播或兜底 | 修复子流程 |
| 循环引用 | A 调用 B，B 调用 A | 发布前静态检测阻断 | 调整结构 |
| 配额不足 | 子流程消耗超限 | 运行前阻断 | 等待重置 |

### 5.9 HITL 人工卡点节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 在流程中插入人工审批/填写/确认，暂停执行直至处理 |
| 适用 | 高风险动作前确认、需要人工补录信息、抽检复核 |
| 用户侧约束 | 审批人仅限本人或同组织成员；不可指定平台外用户 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `context` | in | object | 是 | 提交给审批人查看的上下文（可脱敏） |
| `decision` | out | enum | 是 | `approved` / `rejected` / `timeout` |
| `form_data` | out | object | 否 | 审批人填写内容 |
| `comment` | out | string | 否 | 审批意见 |
| `handler` | out | object{id,name} | 是 | 处理人 |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| form_schema | array<object> | 否 | 空 | 字段类型、必填、校验规则 |
| assignee_mode | enum | 是 | `self` | `self` / `org_role` / `specific_user` |
| assignee_refs | array<string> | 条件必填 | 空 | 非 `self` 时必填，且须在本组织内 |
| timeout_minutes | integer | 是 | 60 | 5–10080 |
| on_timeout | enum | 是 | `reject` | `reject` / `approve` / `escalate` |
| escalate_to | string | 条件必填 | 空 | `escalate` 时必填 |
| mask_fields | array<string> | 否 | 空 | 审批视图中打码字段 |
| allow_delegate | boolean | 否 | false | 是否允许转交 |

**数据流转**：流程到达 → 生成待办 → 通知审批人 → 暂停并持久化快照 → 审批动作 → 恢复执行；恢复时校验执行版本与处理人权限。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 审批人缺失 | 未配置或成员被移除 | 运行前阻断（E-112） | 重新配置 |
| 超时 | 超过设定时长 | 按 `on_timeout` 处理，输出 `timeout` | 调整策略 |
| 执行快照失效 | 工作流已发布新版本 | 以发起时锁定版本恢复 | 无需动作（系统保证） |
| 重复处理 | 多人同时处理 | 先到生效，后到提示“已处理” | 查看处理结果 |
| 权限变更 | 处理时已无权限 | 拒绝处理并提示 | 由有权限者处理 |
| 拒绝后无分支 | `rejected` 端口未连 | 保存阻断 | 连接拒绝分支 |

### 5.10 子 Agent 节点

**节点定义**

| 项 | 内容 |
|---|---|
| 用途 | 将任务交给一个已发布的智能体自主完成，返回其结论与过程摘要 |
| 与子工作流区别 | 子工作流是确定性编排；子 Agent 是自主决策（步数、工具选择由 Agent 决定） |
| 适用判定 | 任务步骤不确定、需要多轮工具选择时用子 Agent；流程固定可枚举时用子工作流 |

**出入参**

| 端口 | 方向 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `task` | in | string | 是 | 任务描述 |
| `context` | in | object | 否 | 上下文与可用资料 |
| `answer` | out | string | 是 | 结论文本 |
| `structured` | out | object | 否 | 声明输出契约时 |
| `steps` | out | array<object> | 否 | 过程摘要（脱敏后），用于 Trace |
| `usage` | out | object{tokens,cost,steps} | 是 | 计量 |
| `status` | out | object{success,reason} | 是 | 终止原因（完成/超步数/超预算/失败） |

**配置字段**

| 字段 | 类型 | 必填 | 默认 | 约束 |
|---|---|---|---|---|
| agent_ref | string | 是 | — | 必须已发布且已授权 |
| max_steps | integer | 是 | 10 | 1–30，且不高于套餐上限 |
| tool_scope | array<string> | 否 | 空 | 仅可使用授权工具子集 |
| memory_mode | enum | 是 | `private` | `private` / `none`；公共记忆需管理员开启 |
| output_contract | object | 否 | 空 | 结构化输出 schema |
| budget_tokens | integer | 否 | 套餐默认 | 超出即终止 |
| timeout_ms | integer | 否 | 平台默认 | 上限受套餐约束 |
| allow_clarify | boolean | 否 | false | 允许向用户追问（站内对话场景） |

**数据流转**：任务与上下文 → 子 Agent 自主规划与工具调用 → 输出结论与过程摘要 → 计量上报；过程摘要进入 Trace，默认不展示给终端用户。

**异常状态**

| 状态 | 触发条件 | 表现 | 用户可采取动作 |
|---|---|---|---|
| 超出步数 | 达到 `max_steps` | 返回部分结果 + `status.reason=step_limit` | 提高上限或改子工作流 |
| 超出预算 | token 超预算 | 终止并返回已完成部分 | 提高预算或简化任务 |
| 工具越权 | 请求未授权工具 | 拒绝该次调用，Agent 收到失败原因 | 调整工具范围 |
| 输出不合契约 | 结构化校验失败 | 重试 1 次，仍失败按错误策略 | 放宽契约或改用子工作流 |
| 无结论 | 超时或空输出 | 标记失败并给出可读原因 | 重试或改写任务 |
| Agent 下线 | 引用失效 | 运行前阻断 | 更换 Agent |

## 7. 数据归属、资源授权与配额【执行引擎】

### 7.1 归属与隔离

| 对象 | 归属字段（产品定义） | 可见性 |
|---|---|---|
| 工作流 | `owner_type`：`cus`（客户用户）/ `usr`（后台普通用户）+ 归属 ID | 私有 / 公开只读 / 模板 |
| 执行实例 | `owner_type` + 归属 ID + 会话 ID | 仅归属人 |
| 会话与记忆 | `owner_type` + 归属 ID | 仅归属人；记忆按模式区分 |
| 知识库 | `owner_type` + 归属 ID + 是否公共 | 私有 / 公共只读 / 公共授权 |
| 上传文件 | `owner_type` + 归属 ID + 会话 ID | 仅归属人 |

强制规则：

1. 所有列表、详情、编辑、执行、删除接口必须带归属过滤；鉴权失败统一返回 404（不暴露资源是否存在），避免探测。
2. 跨归属访问一律拒绝并记录审计。
3. 公共资源只读；需修改时复制为私有副本。
4. 后台普通用户（`usr`）除归属过滤外，必须叠加角色数据权限（`data_scope`）范围；两者同时满足才可访问。
5. 双身份采用 L1 身份关联：允许通过 `customer.system_user_id` 建立“同一自然人”映射，但两套主体各自登录、数据分域，资产不复制、不迁移、不合并；规则见 3.2。

### 7.2 资源授权模型

| 资源 | 授权粒度 | 默认策略 |
|---|---|---|
| 模型 | 按套餐/用户白名单 | 仅基础模型可用 |
| 知识库 | 公共库按套餐；私有库按归属 | 公共库需显式授权 |
| 工具 | 按工具分组授权 | 默认关闭 |
| 子 Agent | 按已发布清单 | 默认关闭 |
| 节点类型 | 按套餐 | 代码/HTTP 永久关闭 |

### 7.3 配额与成本

| 配额项 | 计量口径 | 超限行为 |
|---|---|---|
| 模型 token | 输入+输出 token 折算 | 调用前预估拦截；调用后结算 |
| 工具调用次数 | 成功+失败计数 | 超限阻断 |
| 知识库检索次数 | 每次检索计 1 | 超限阻断 |
| 向量写入条数 | 批次条数 | 超限阻断 |
| 运行次数/并发 | 每日运行数、同时运行数 | 超限排队或拒绝（按套餐） |
| 单次运行预算 | tokens/耗时/步数 | 触发即终止并返回部分结果 |

配额来源（双主体，已确认）：

| 主体 | 额度来源 | 说明 |
|---|---|---|
| 客户用户（`cus`） | 会员等级 | 等级定义周期额度与并发上限，升降级即时生效 |
| 后台普通用户（`usr`） | 角色套餐 | 角色绑定套餐，套餐映射到同一配额项集合（具体映射见 Q7） |

补充规则：

1. 计量必须精确到“用户 + 工作流 + 节点”，用于账单与优化建议。
2. 预估阶段即可拒绝（如输入 token 已超预算），避免先扣费后失败。
3. 用户可见“剩余额度、重置时间、本次消耗”，避免黑箱。
4. 管理员可设置硬上限与告警阈值（如 80% 提醒）。

### 7.4 高风险节点安全策略

| 风险 | 策略 |
|---|---|
| 代码执行 | 用户侧永久关闭；不提供“申请开放”入口 |
| 任意 HTTP | 默认关闭；开放时仅允许域名白名单、禁内网地址与元数据地址、限制响应大小与方法 |
| 工具越权 | 工具侧声明所需权限，平台按用户授权校验；凭证不下发 |
| 提示词注入 | 检索片段与用户输入标记为不可信内容，系统提示中声明边界；输出侧做敏感信息检测 |
| 文件上传 | 类型白名单、大小限制、内容检测、隔离存储 |
| 数据外泄 | 输出侧敏感字段打码；Trace 导出默认脱敏 |

## 8. 场景判断标准

### 8.1 固定工作流 vs Agentic 自主编排

| 判断维度 | 倾向固定工作流 | 倾向 Agentic |
|---|---|---|
| 步骤可枚举性 | 步骤固定、顺序明确 | 步骤依输入动态变化 |
| 结果确定性要求 | 强（合规、财务、审批） | 弱（探索、研究、创作） |
| 失败成本 | 高，需要可回滚与可审计 | 低，可重试 |
| 工具选择 | 预先确定 | 需模型决定用哪个工具 |
| 可测试性 | 可构造稳定用例 | 难以穷举 |
| 成本可预估性 | 高 | 低（步数不定） |
| 推荐 | 优先固定工作流 | 子 Agent 节点嵌入固定流程（混合） |

判定规则（产品口径）：

1. 若 80% 以上请求的步骤序列一致 → 固定工作流。
2. 若需要“模型自主决定下一步”且失败可接受 → 子 Agent 节点。
3. 若两者皆需 → 用固定工作流做主干，局部用子 Agent 承担不确定段，并设置步数与预算上限。
4. 涉及审批、付款、对外发送等不可逆动作 → 必须固定路径 + HITL，不允许纯自主。

### 8.2 RAG 适用与不适用

| 适用 | 原因 |
|---|---|
| 企业私有文档问答（制度、手册、合同） | 知识在文档中，需溯源 |
| 需要引用出处的客服/法务/医疗辅助 | 必须可追溯 |
| 知识更新频繁但结构松散 | 检索比重训更快 |
| 长尾问题覆盖 | 无法穷举意图 |

| 不适用 | 原因与替代 |
|---|---|
| 强结构化计算、报表汇总 | 用工具/数据库查询，不用检索 |
| 实时强一致数据（库存、余额） | 走实时接口，检索结果会过期 |
| 需要跨文档推理与全局统计 | 检索命中率低，改用分析型工具或预先聚合 |
| 文档质量差、无结构、无标注 | 先做治理，否则召回不可用 |
| 极低延迟要求（如毫秒级） | 检索+重排链路成本高，考虑缓存或预生成 |
| 完全通用常识问题 | 直接模型回答即可 |

### 8.3 检索质量与成本权衡（产品口径）

| 调节项 | 提升召回 | 降低成本 | 副作用 |
|---|---|---|---|
| top_k 增大 | 是 | 否 | 噪声增多、上下文变长 |
| 阈值提高 | 否 | 是 | 漏召回 |
| 开启重排 | 提升准确率 | 否 | 延迟增加 |
| 查询改写 | 是 | 否 | 额外 token |
| 片段长度减小 | 否 | 是 | 上下文不完整 |
| 多知识库合并 | 是 | 否 | 冲突与去重问题 |

产品要求：默认配置应“准确优先，成本可控”；面板需展示当前配置的预估延迟与 token 消耗区间。

### 8.4 幻觉风险规避（产品口径）

| 措施 | 说明 |
|---|---|
| 引用强制 | 知识型回答默认要求引用；无引用需显式标记“未溯源” |
| 低温度 | 抽取/判定类默认 ≤ 0.3 |
| 结构化输出 | 关键字段用 JSON Schema 约束并校验 |
| 兜底话术 | 空召回或低分命中时明确告知“未找到依据”，禁止编造 |
| 冲突处理 | 多来源冲突时展示差异，不合并成单一结论 |
| 可回溯 | 每条结论可点开引用原文 |
