# 听音蓝牙耳机消费级电子测试计划

## 1. 测试概述

### 1.1 测试目标
针对"听音"品牌蓝牙耳机的完整生产工艺流程，验证MES/MRP2系统在消费级电子产品制造中的功能正确性、数据完整性和流程贯通性。

### 1.2 测试范围
- **产品范围**：听音T100真无线蓝牙耳机
- **模块范围**：MRP2（销售预测/MPS/MRP/CRP）→ MES（基础数据/制造计划/工单执行/生产报工/物料流转/品质检测）→ 采购 → 库存
- **工艺范围**：SMT贴片 → 焊接 → 组装 → 功能测试 → 老化测试 → 包装

### 1.3 测试环境
- 服务地址：`http://127.0.0.1:9998`
- 前端地址：`http://127.0.0.1:9998/panel/mes/`
- 登录账号：admin / admin

### 1.4 测试数据初始化
运行 `python tests/seed_bluetooth_data.py` 初始化测试数据。

## 11. 测试注意事项

1. **批次管理**：蓝牙耳机生产需严格跟踪批次号，测试时确保每道工序的批次号正确传递
2. **损耗率**：SMT贴片和组装工序存在损耗，测试时注意验证损耗率计算
3. **老化测试时间**：老化测试标准工时120分钟，测试时注意时间字段处理
4. **多工序依赖**：后工序需等待前工序完工，测试时注意工单顺序执行
5. **数据一致性**：跨模块数据联动需确保一致性，测试后验证各模块数据匹配
6. **环境隔离**：测试前确保数据库干净，避免历史数据影响测试结果
7. **权限验证**：测试不同角色（生产主管、操作员、质检员）的功能权限
8. **性能测试**：大数据量场景下验证系统响应时间
