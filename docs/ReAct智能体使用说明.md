# ReAct 模式智能体使用说明

## 问题分析

你遇到的 `agent.graph_definition: None` 问题是因为智能体的结构图配置还没有保存到数据库。

## 解决方案

### 方法一：使用 Python 脚本导入（推荐）

1. **运行导入脚本**

   在项目根目录下运行：

   ```bash
   python import_agent_config.py
   ```

2. **按菜单操作**

   - 选择 `1` 查看所有智能体，确认你的智能体ID
   - 选择 `2` 导入配置
   - 输入智能体ID
   - 选择配置文件（推荐 `ReAct任务分解智能体.json`）
   - 确认导入

### 方法二：通过前端界面导入

1. 打开前端界面，进入智能体编辑页面
2. 点击"结构图"或"编辑流程图"
3. 点击"导入"按钮
4. 选择 `docs/ReAct任务分解智能体.json` 文件
5. 保存

## ReAct 模式说明

### ReAct 模式的核心概念

```
Reasoning (思考) → Acting (行动) → Observing (观察) → 循环迭代
```

### 在本项目中的实现

| 组件 | 说明 |
|-----|-----|
| **Skill (不是必须的)** | 预定义的功能模块，可选使用 |
| **LLM 节点** | 可以作为思考、行动、观察等各种角色 |
| **Condition 节点** | 用于判断是否继续循环 |
| **Loop 节点** | 用于循环计数 |
| **JSON Extractor** | 用于提取结构化数据 |

## 常见问题

### Q: graph_definition 仍然是 None？

A: 确保：
1. 配置文件格式正确（包含 nodes 和 edges）
2. 使用导入脚本后等待保存完成
3. 重新查询智能体确认

### Q: 没有 Skill 可以使用 ReAct 吗？

A: **完全可以！** Skill 只是一种可选的行动方式，你可以：
- 使用 LLM 直接生成内容作为行动
- 使用 HTTP 节点调用外部 API
- 使用 Code 节点执行代码

### Q: 如何调整循环次数？

A: 修改配置文件中的：
- `loop_max` 控制最大循环次数
- `condition` 中的判断条件

### Q: 如何在前端查看结构图？

A: 在智能体详情页找到"结构图"或"流程图"相关的按钮进入编辑界面。
