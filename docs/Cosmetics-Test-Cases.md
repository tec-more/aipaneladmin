# 花妍美妆产品MES/MRP2系统测试计划

## 1. 测试概述

### 1.1 测试目标
针对"花妍"品牌美妆产品的完整业务流程，验证MES/MRP2系统在美妆行业中的功能正确性、数据完整性和流程贯通性。重点验证从产品生成、制造计划、采购管理到销售订单的全链路业务流程。

### 1.2 测试范围
| 模块 | 测试内容 |
|------|----------|
| 产品管理 | 产品分类、属性管理、产品创建、产品变体、产品规格关联 |
| 基础数据 | 物料CRUD、BOM版本管理、工艺路线配置、工作中心管理 |
| MRP2 | 销售预测、MPS主生产计划、MRP物料需求计算、CRP能力需求计算 |
