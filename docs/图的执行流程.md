# 本文档用来说明图的执行流程
前端使用vueflow库来实现图的可视化和交互。初始化完成后，图数据保存在后端的数据库中。
图是一个个节点，包含节点的类型、参数、输入输出等信息。
节点之间的连接，表示任务的依赖关系。
节点的执行顺序，根据图的拓扑排序来确定。
节点的执行结果，会保存在节点的输出端口中。
## 图的状态
图的状态可以是以下几种：
- 初始化中：图正在初始化，节点和边正在加载中。
- 执行中：图正在执行，节点正在按顺序执行。
- 执行完成：图执行完成，所有节点都已完成。
- 执行失败：图执行失败，有一个节点执行失败。
- 已暂停：图执行被暂停，等待用户继续执行。
## 图在执行过程中各个状态的上下文管理
图在执行过程中，会维护一个上下文，用于存储节点的执行结果和参数。
- 初始化中：上下文为空，节点的执行结果和参数会保存在上下文的节点中。
- 执行中：节点的执行结果和参数会保存在上下文的节点中。
- 执行完成：上下文为空。
- 执行失败：上下文为空。
- 已暂停：上下文为空。
- 继续执行：节点的执行结果和参数会保存在上下文的节点中。
## 图的上下文管理
图的上下文管理，包括节点的执行结果和参数的存储和检索。
