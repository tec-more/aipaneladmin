## 🚀 快速开始

### 第一次使用？

1. **阅读** [快速参考卡片](quick_reference.md) - 了解基本概念
2. **选择** 合适的模板 - 推荐从API集成请求模板开始
3. **填写** 需求信息 - 按照模板要求填写
4. **提交** 给AI - 将填写好的内容发送给AI
5. **审查** 结果 - 检查AI生成的代码

### 熟悉了？

直接使用 [快速参考卡片](quick_reference.md) 中的"标准三段式模板"
